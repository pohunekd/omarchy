Onboarding gets an automatic mode that applies only the items you grant, under a `pohunek-onboard` profile that allows exactly those commands (pohunek 0.43.0, Claude or Codex), and per agent home you can add the pohunek agent skill. **Undo onboarding** in Help lists what the recorded run added (projects, profiles, session groups, hooks and skills), asks once and removes it, keeping anything you changed since.
