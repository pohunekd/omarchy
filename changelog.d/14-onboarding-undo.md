Onboarding gets an automatic mode that applies the items you grant without asking, under a `pohunek-onboard` profile that allows those commands on top of your own agent permission settings (pohunek 0.43.0, Claude or Codex), and per agent home you can add the pohunek agent skill. **Undo onboarding** in Help removes what the recorded run provably added: with the tool's window left open until the onboard session ends, the projects, profiles, session groups, hooks and skills it added, keeping anything you changed since; otherwise only its manual projects and its own profile, listing the rest with its command.
