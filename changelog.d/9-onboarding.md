A Get started card in the panel sets pohunek up from a verified release (or starts on a machine that has it), asks once after showing every change, and starts a guided onboard manager that proposes projects, groups, profiles and hooks one at a time. Agent hooks are chosen per agent home and start unticked; the assistant package is installed and verified by the tool while `pohunek setup` cannot install it, and onboarding needs pohunek 0.42.0 or newer.
